Política de Privacidad de ColeTec

Última actualización: 5 de junio de 2026

Esta política de privacidad describe cómo la aplicación móvil ColeTec (en adelante, "la Aplicación"), identificada con el nombre de paquete com.cajami.coletec, recopila, utiliza y protege tu información.

1. Recopilación de Información y Datos del Usuario

ColeTec es una aplicación completamente offline. Esto significa que:

  • Toda la información referente a colegios, cursos, alumnos, matrículas, asistencias y configuraciones se almacena de forma local en tu dispositivo utilizando una base de datos SQLite encriptada.
  • La Aplicación no tiene servidores propios ni transmite ninguna de tus bases de datos, datos escolares, de alumnos o personales a través de internet.

2. Datos de Carácter Sensible y Autenticación Biométrica

La Aplicación ofrece seguridad de acceso mediante biometría (huella digital o reconocimiento facial):

  • Esta verificación es procesada íntegramente por las APIs oficiales del sistema operativo de tu dispositivo (Android).
  • La Aplicación no tiene acceso, no lee, no almacena y no recopila tus datos biométricos en ningún momento. Solo recibe una confirmación de éxito o fallo por parte del sistema operativo.

3. Permisos del Dispositivo

La Aplicación puede solicitar acceso a la memoria local del dispositivo (archivos/almacenamiento) únicamente para permitirte realizar y restaurar copias de seguridad de tus datos mediante archivos JSON de forma manual.

4. Menores de Edad

ColeTec está diseñada para ser utilizada exclusivamente por docentes y personal administrativo escolar. Aunque la aplicación permite gestionar datos de alumnos (los cuales pueden ser menores de edad), esta información se mantiene 100% local en el dispositivo del docente y no es recolectada, compartida o procesada por terceros.

5. Cambios a esta Política de Privacidad

Es posible que actualicemos nuestra Política de Privacidad ocasionalmente. Te recomendamos revisar esta página periódicamente para conocer cualquier cambio.
