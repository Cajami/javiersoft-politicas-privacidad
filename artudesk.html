Política de privacidad de ArtuDesk

Última actualización: 11 de noviembre de 2026

Esta política explica cómo la aplicación móvil ArtuDesk (paquete com.cajami.artudesk) trata la información cuando se utiliza para compartir y controlar una pantalla entre un dispositivo Android y una computadora Windows.

1. Información que trata la aplicación

ArtuDesk no requiere crear una cuenta y no solicita nombre, correo electrónico, contactos ni ubicación. No incluye publicidad ni herramientas de analítica.

  • Datos temporales de conexión: al iniciar una sesión se genera una clave aleatoria. La aplicación utiliza Firebase Realtime Database para intercambiar temporalmente esa clave, el estado de la sesión y los datos técnicos de negociación necesarios para conectar los dispositivos. La aplicación solicita borrar esos datos cuando termina o falla la sesión; si el dispositivo no tiene conexión, la eliminación puede no completarse de inmediato.
  • Pantalla compartida: solo después de que el usuario inicia la acción y acepta el permiso de captura de Android, ArtuDesk transmite la imagen de la pantalla al equipo que se conecta. El contenido de pantalla no se guarda en los servidores de señalización de ArtuDesk.
  • Control remoto: durante una sesión, la computadora conectada puede enviar acciones de toque y texto para controlar el dispositivo. El servicio de accesibilidad de ArtuDesk se utiliza para aplicar esas acciones; no procesa campos identificados como contraseñas.
  • Datos de red: WebRTC y el servicio público STUN de Google se utilizan para establecer la conexión entre dispositivos. La negociación puede incluir información técnica de red, como direcciones IP, necesaria para conectarlos.
  • Diagnósticos: la aplicación puede guardar en el almacenamiento privado del dispositivo un registro técnico local de etapas y errores, sin guardar el texto de los errores ni el contenido escrito. No se envía automáticamente ese registro al desarrollador.

2. Cómo se transmite la información

La base de datos de Firebase se usa para señalización y coordinación de la sesión, no para almacenar las imágenes de pantalla. Una vez establecida, la conexión WebRTC transmite la pantalla y las acciones directamente entre los dispositivos mediante transporte cifrado. Google puede tratar datos técnicos de conexión al prestar Firebase y STUN, conforme a sus propias políticas de privacidad.

3. Permisos

  • Captura de pantalla: Android solicita autorización cada vez que se inicia una sesión de compartir pantalla.
  • Accesibilidad: el usuario debe activar el servicio de ArtuDesk en los ajustes de Android para recibir y ejecutar acciones remotas de toque y texto. El servicio se utiliza para las funciones de control descritas aquí.
  • Red y notificaciones: el acceso a Internet y al estado de la red permite conectar los dispositivos; las notificaciones informan de una sesión activa.

El usuario puede detener la sesión desde ArtuDesk o desde Android y desactivar el servicio de accesibilidad en los ajustes del sistema.

4. Conservación y eliminación

ArtuDesk no mantiene una cuenta ni un historial de sesiones en un servidor propio. Los datos de señalización se solicitan eliminar al finalizar la sesión. Los diagnósticos permanecen en el almacenamiento privado del dispositivo y pueden eliminarse borrando los datos de la aplicación o desinstalándola. Los proveedores de infraestructura pueden conservar registros técnicos conforme a sus propias políticas.

5. Menores de edad

ArtuDesk es una herramienta de acceso remoto que requiere que el usuario inicie y autorice la captura de pantalla y habilite el control remoto. No está dirigida a menores de 13 años.

6. Cambios a esta política

Esta política puede actualizarse cuando cambien la aplicación o sus prácticas de datos. La fecha de actualización se indicará al inicio de esta página.
